Backend Technologies
Python server, authentication, API structure and routing
Backend
🌶️
Flask
v3.0.0
Lightweight Python web framework. Runs the entire backend API server. All 18 API endpoints are built as Flask routes, organized into 5 Blueprint modules for clean separation of concerns.
REST API Server Route Handlers Blueprint Modules JSON Responses File Downloads
app.py api/auth_routes.py api/project_routes.py api/validation_routes.py api/map_routes.py api/admin_routes.py
Backend
🔓
Flask-CORS
v4.0.0
Adds Cross-Origin Resource Sharing headers to all Flask responses. Allows the React frontend on port 3000 to call the Flask API on port 5000 without the browser blocking requests.
Cross-Origin Requests Frontend ↔ Backend
app.py — CORS(app)
Backend
🔧
Werkzeug
v3.0.1
The WSGI utility library that Flask is built on. Provides the development server, request/response objects, and file serving utilities used when sending the 2D layout PNG to the user.
WSGI Server Request Objects File Serving
app.py — send_file() project_routes.py
Backend
🔐
hashlib + base64
Python Standard Library
Built-in Python modules. hashlib hashes passwords with SHA-256 before storing them in the database. base64 encodes the session token that is sent to the frontend after login.
Password Hashing Session Tokens Auth Security
api/auth_routes.py hash_password() generate_token() decode_token()
Backend
📋
Python logging
Standard Library
Standard Python logging module. Writes timestamped server activity to both the terminal and a log file — every login, project creation, validation, and error is recorded.
Server Logs Error Tracking File + Console Output
app.py — logging.basicConfig urban_planning.log logger.info() / .error()
Backend
⚙️
python-dotenv
v1.0.0
Loads environment variables from a .env file. Used to store the Flask secret key and other config values outside of the source code, following security best practices.
Secret Key Config Environment Variables Security
app.py — SECRET_KEY .env file (create yourself)

Database
Data storage, schema, and query management
Database
🗃️
SQLite
Built into Python
Serverless, file-based relational database. Stores everything in a single file urban_planning.db. No separate DB server needed. Contains 8 tables covering users, projects, land, requirements, predictions, validations and outputs.
User Accounts Project Data Land Details Predictions HITL Records Output Files
database/schema.sql database/db_init.py database/db_manager.py app.py — get_db()
Database
🔌
sqlite3 Module
Python Standard Library
Python's built-in SQLite driver. Manages connections, executes parameterized queries (preventing SQL injection), and uses Row factory to return query results as dictionaries instead of plain tuples.
DB Connection SQL Queries SQL Injection Prevention Row → Dict Mapping
app.py — query_db() app.py — execute_db() database/db_manager.py conn.row_factory
Database
📦
json Module
Python Standard Library
Python's JSON serializer. Since SQLite doesn't have a native JSON column type, complex objects like coordinates, dimensions, requirements, and layout predictions are serialized to JSON strings before saving and parsed back out on retrieval.
Serialize Coordinates Serialize Layouts Serialize Requirements API Request/Response
json.dumps() — save json.loads() — read All route files

AI / ML Technologies
Layout generation engine, constraint system, and training data pipeline
AI/ML
🔥
PyTorch
v2.1.2
Deep learning framework for building the custom GNN layout model. The current codebase uses a rule-based placeholder. When your GNN is trained, its model.forward() replaces the rule-based function in _rule_based_layout().
Custom GNN Model Model Training Tensor Operations Model Inference
models/layout_generator.py _rule_based_layout() ← replace requirements.txt
AI/ML
🕸️
PyTorch Geometric
v2.4.0
Extension library for Graph Neural Networks on top of PyTorch. The land parcel, buildings, and road network are naturally represented as graphs — nodes are buildings/intersections, edges are roads. GNN learns spatial relationships.
Graph Neural Network Spatial Encoding Node/Edge Features Layout Decoding
models/layout_generator.py GNNEncoder (planned) LayoutDecoder (planned)
AI/ML
🔢
NumPy
v1.26.3
Fundamental numerical computing library. Provides fast array operations needed for coordinate calculations, polygon geometry, distance computations, and feature vector construction during layout generation.
Coordinate Arrays Geometry Math Feature Vectors Numerical Ops
models/constraint_validator.py models/layout_generator.py
AI/ML
📐
SciPy
v1.11.4
Scientific computing library. Used for Delaunay triangulation to generate optimal road network topology between building centroids — the triangulation gives the minimal connected graph that links all buildings.
Delaunay Triangulation Road Network Graph Geometric Optimization
models/layout_generator.py scipy.spatial.Delaunay RoadNetworkBuilder
AI/ML
⚗️
scikit-learn
v1.3.2
ML utilities library. Provides preprocessing tools, train/test split, and scoring metrics used during model training and evaluation when benchmarking the custom GNN layout model against the synthetic dataset.
Data Preprocessing Train/Test Split Model Evaluation
models/data_generator.py Model training pipeline
Custom
✅
Custom Constraint Engine
Built from scratch
Pure-Python geometry system written from scratch using the Shoelace formula, cross-product orientation tests, and AABB overlap checks. Validates 8 hard constraints on every generated layout with a 10-retry loop.
No Building-Road Collision All Buildings Accessible Gates Exist Boundary Wall ≥70% Space Used
models/constraint_validator.py _polygons_overlap() _building_touches_road() _polygon_area() — Shoelace
Custom
🏭
Synthetic Data Generator
Built from scratch
Custom training data pipeline. Generates thousands of random land parcels, requirements, and valid layouts in JSON Lines format for training the GNN. Run once from command line to produce a dataset.
Training Data Random Land Parcels JSON Lines Output CLI Tool
models/data_generator.py python data_generator.py --samples 5000 data/training.jsonl

2D Layout Render Boundary Wall Building Rectangles Road Polygons Green Space Patches 300 DPI PNG Export

Image Processing PNG Encoding Format Conversion

Map & Geospatial Services
All free and open-source — zero API key required
Maps
🗺️
OpenStreetMap
Free, no key
Open-source crowd-sourced map of the world. Provides the map tile images displayed in the Leaflet map widget. Tile URL format: {s}.tile.openstreetmap.org/{z}/{x}/{y}.png. No account or API key needed.
Map Tiles Satellite Imagery Feel Zoom Levels 1–19 Free Forever
frontend/NewProjectPage.jsx api/map_routes.py L.tileLayer(OSM url)
Maps
📍
Nominatim
OSM Geocoder — Free
OpenStreetMap's free geocoding service. Converts a city/address name (e.g. "Hosur Tamil Nadu") into lat/lng coordinates to pre-fill the land input form. Limited to 1 request/second — the backend returns the URL and the frontend calls it directly.
Forward Geocoding Address → Lat/Lng India Filter Free, No Key
api/map_routes.py — /geocode nominatim.openstreetmap.org countrycodes=in
Maps
📏
geopy
v2.4.1
Python geocoding library. Used for geographic distance calculations between coordinates and to verify that the entered land is within India's bounding box (lat 6.5°–35.5°, lng 68°–97.5°).
Distance Calculation India Bounds Check Coordinate Validation
api/map_routes.py app.py — validate_coordinates()
Maps
🔷
Shapely
v2.0.2
Python geometry library for working with 2D shapes — polygons, lines, points. Used for precise intersection tests between land parcels, buildings and roads during constraint validation beyond the custom pure-Python geometry code.
Polygon Operations Intersection Tests Area Calculation Geometry Objects
models/constraint_validator.py models/layout_generator.py
